# 🎵 Music Player Concept

Uma experiência interativa inspirada em músicas que marcaram momentos importantes.

## 📖 Sobre o projeto

Este projeto nasceu da vontade de unir programação e música em uma única experiência.

A proposta é criar uma página onde cada música possui sua própria identidade, reunindo:
- capa da música;
- um player interativo;
- uma história pessoal relacionada àquela obra.

O projeto está sendo desenvolvido para praticar e aprimorar conhecimentos em HTML, CSS e futuramente JavaScript.
